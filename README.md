# 🏦 Banking Data Analytics Dashboard  

## 📌 About the Project  
This **End-to-End Data Analytics Project** in the **Banking Domain** demonstrates the complete data pipeline from ingestion to visualization.  
We start by dumping raw data into **MySQL**, perform **Exploratory Data Analysis (EDA)** using **Python**, and finally build an **interactive Power BI dashboard** to uncover insights.  

The dashboard presents:  
- 📊 **Loan Analysis**  
- 💰 **Deposit Analysis**  
- 📈 **Overall Dataset Summary**  

---

### **1️⃣ Summary KPIs**

---

## 📊 Project Workflow  

### **1️⃣ Data Ingestion – Dumping Data to MySQL**  
- Collected the banking dataset.  
- Used **MySQL Workbench** / Python connector to insert the dataset into a MySQL database.  
- Structured the database for easy querying.  

### **2️⃣ Exploratory Data Analysis (EDA) – Python**  
- **Libraries used:** Pandas, NumPy, Matplotlib, Seaborn  
- **Data cleaning:**  
  - Handled missing values.  
  - Converted data types.  
  - Removed duplicates.  
- **Feature engineering** for better insights.  
- Generated **summary statistics** and visualizations for understanding trends.  

### **3️⃣ Dashboard Building – Power BI**  
- Connected Power BI to MySQL database.  
- Designed **interactive dashboard** showing KPIs and breakdowns.  
- Created visuals for:  
  - Total Clients & Accounts  
  - Loan vs Deposit analysis  
  - Business Lending insights  
  - Savings & Foreign Currency account breakdowns
